Fake Paper Generator and Citation network Visualisation

## Requirements

- Python 3.x
- NetworkX
- Matplotlib

You can install the required libraries using the following commands:

```sh
pip install networkx matplotlib
```

## Usage

This project for now consists of two scripts:

1. generate_fake_papers.py: Generates fake research papers with random titles, authors, and references which can be used for creating a stacking graph

1a. In the fakepapergenerator.py script, edit the variable num_papers to specify the number of fake papers you want to generate.
1b. Save the script and run it to generate the fake research papers and save them to a JSON file (fake_papers.json).
1c. You can also tweak the JSON file if you would like to experiment with the graph results.

2. visualize_citation_network.py: Visualizes the citation network of the generated papers using NetworkX and Matplotlib.

2a.Ensure that fake_papers.json has been generated by running the previous script.
2b.Run the visualize_citation_network.py script to visualize the citation network from the generated JSON file.
2c. Reading the Citaion Network Graph:
Nodes:
Blue nodes: Represent the authors.
Lightblue nodes: Represent the papers.
Edges:
Blue edges: Connect an author to their own paper.
Green edges: Represent citations from one paper to another author.
Red edges: Indicate bidirectional citations between two authors (citation ring).
